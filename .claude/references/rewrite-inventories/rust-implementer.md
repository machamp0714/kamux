**散文で件数だけ書くと、器が変わったときに古くなる。** 下を打った出力を読むこと。非空行のうち、見出し・code fence の区切りと中身・表の区切り行・`>` だけの行を落とした残りが補集合である（落とした分は検査 7 / 8 / 9 / 11 と frontmatter の明示除外が覆う）。

```bash

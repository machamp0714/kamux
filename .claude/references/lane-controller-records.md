# lane-controller: 恒久記録と証拠の規律（詳細）

`lane-controller.md` の層2 ファイルである。恒久記録（報告・PR 本文・契約変更要求・台帳行）を書く局面、または証拠に既存コマンドの出力を使う局面で読む。読んだら ledger へ `参照: lane-controller-records.md（<局面>）` の 1 行を記帳する。章表記の分界は本体「章の書き方」に従う。

## 借用コマンドの既知の罠

「証拠に借りたコマンドの出力が、2 状態を区別するか」（本体）の具体例。いずれも実測済み。

- `<コマンド> | tail -n` の終了コードは `tail` のものである。検証コマンドをパイプしない。単独で走らせて `$?` を読む（team-lead がゲートで踏み、`cargo test` が 8 件しか見えなかった。実際は 783）
- `cargo test --workspace` に `--no-fail-fast` を付ける。付けないと先頭 target の赤で残り 3 target が黙って飛ぶ
- `gh pr merge --delete-branch` が worktree から `fatal: 'main' is already used by worktree` を返しても、マージは成功していることがある。`gh pr view <n> --json state,mergeCommit` と `git ls-remote --heads origin <br>` で確かめる
- `git status --porcelain` は `.gitignore` 配下の成果物を見ない。`git ls-files -s` はインデックスのモードを返すので worktree の実行ビット喪失を見ない
- 後片付けの glob には `(N)` か `2>/dev/null` を付ける。zsh の no-match はコマンド全体を中断し、先行パターンの削除が 1 つも実行されないまま終了ステータスだけが返る
- ローカルの緑は CI の緑ではない。worktree に残ったバイナリで全緑になり、CI だけが `resource path … doesn't exist` で落ちた実例がある

## 観測点の正典

本体の「証拠・処方・実体・裁定・一覧・工程・上書き・参照・転記・件数・数値」の 12 規則について、効いているかを判定する観測点はここが持つ。ゲート（棚卸し）とレビューが使う。

| 規則（本体の節名） | 観測点 |
|---|---|
| 証拠に借りたコマンドの出力が、2 状態を区別するか | 証拠に使った各コマンドについて「不合格ならこう見える」の 1 行が報告に在ること |
| 処方・訂正が閉じる族の境界を書く | 訂正指示に「この処方が閉じる族」「同型の残り」の 1 行が在ること。「1 語だけ」と書いた便に、その語での `grep -c` の出力が併記されていること。値を差し替えたコミット本文に、その値を定める章の「測り方」の逐語が引かれていること |
| 同じ作業に実体は 1 体だけ | 起動指示に、先行実体の停止を確かめた出力が 1 行あること |
| 裁定は `SendMessage` を待たず、契約ファイルの末尾を自分で読む | `grep -c '§[0-9]*' <ledger>` が、そのフェーズで着地した契約章の数以上を返すこと。契約変更要求を上げたレーンの ledger に「契約ファイルの末尾を自分で読んだ」記録が在ること |
| 一覧に載せないと判断したものは、件数と理由を書く | ledger の deferred minor 行の件数と、PR 単位レビューの Minor 件数の和が一致すること |
| 工程を定義したら、産物の書き先・書き手・時点を同じ場所に書く | 宣言した工程それぞれに、産物の書き先が 1 行併記されていること |
| 稼働中の他者が使っている状態へ書かない | 成果物を上書きする作業の報告に `lsof <パス>` か `pgrep -f kamux` の出力が 1 行あること |
| 参照は本文照合してから書く | 参照を書いた差分の報告に `grep -n '<引いた逐語>' 00-contracts.md` の出力が 1 参照につき 1 行あること。参照の置換を「旧文字列 0 件」だけで確認した記録が 0 件であること |
| 原本が在る値を手で写さない | 値を写した行に `<ファイル>:<行>` が併記されていること |
| 列挙・件数は機械で導出して突き合わせる | 「N 件」と書いた宣言の直後の実体を数えたコマンドの出力が併記されていること |
| 数値には単位・時点・母数の定義を添える | dispatch と報告の数値に単位が書かれていること。引用した sha に `git merge-base --is-ancestor <sha> origin/main` が 0 を返すこと |

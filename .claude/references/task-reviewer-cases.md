# 実例（task-reviewer）

`.claude/agents/task-reviewer.md` の規則を裏付けた実例。出典はすべて kamux（2026 年 7〜8 月）。

規則の射程を判断するとき、または規則を消してよいか迷ったときに読む。普段は開かなくてよい。

## PR 単位レビューがタスク単位の見落としを捕まえた

stage2 では PR 単位レビューがタスク単位レビュー 5〜8 本分の見落としを 2 回とも捕まえており、2 回とも形は「レビュー指摘への修正そのものが無検証で残っていた」だった。

## テストは緑だが何も守っていない

stage0〜stage3 で 10 例出た。「テストは通るが、その処理を削除しても緑のまま」は stage2 だけで 4 回出ており、そのうち 2 回はレビュー指摘への修正そのものが無検証で残っていた。

- `with_suffix` の `trim_end_matches('-')` を削除しても 43/43 緑
- `SortableCard` の `role: 'article'` を削除しても vitest 311・e2e 19 全緑

根拠となった実測の当時の書き先は `.superpowers/sdd/M2-1-runtime-state/TEAM-LEAD-RULINGS.md:565` である（**恒久的な引用先ではない**。PR #92 でこのファイルは `progress.md`「## 裁定」へ統合された）。

## 呼ぶ側の配線が無検査だった
